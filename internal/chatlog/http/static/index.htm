Chatlog

本地微信聊天记录服务已就绪 — 下面是可直接调用的 HTTP 接口

本服务来自 chenliitaz/chatlog，是 sjzar/chatlog 的 fork， 额外提供公众号汇总与聊天统计。所有数据均在本机处理，不上传任何聊天内容。 


        

      


      

        
🤖 MCP 集成

        

          本服务同时提供两种 MCP 传输方式，接入 AI 助手时优先用第一种：
        

        
    
          
  • 
            Streamable HTTP（推荐）：/mcp —
            ChatWise、Cherry Studio 等支持 Streamable HTTP 的客户端直接填这个地址即可。
          
    • 
          
  • 
            SSE（兼容旧客户端）：/sse — 仅在客户端不支持
            Streamable HTTP 时使用，Claude Desktop 一类需要配合 mcp-proxy 转发。
          
    • 
        

        

          各平台的完整配置步骤见
          MCP 集成指南。
